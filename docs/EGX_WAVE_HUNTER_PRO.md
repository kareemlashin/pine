# صياد موجات EGX PRO — دليل النظام

> **واجهة عربية:** عنوان المؤشر «صياد موجات EGX PRO»، إعدادات EGX بالعربية (معيار EGX، قطع كبير، انتقائي، …)، مجموعة **13 — مضاربة / استثمار**، لوحة **33** صفًا (نظام سوق، دورة 12، كيلي، وايكوف، **ماسح بوابات 7/7**، FVG/POC)، تنبيهات عربية.

## الملفات

## 1. تصميم المنظومة

```
┌──────────────────────────────────────────────────────────────┐
│              EGX WAVE HUNTER PRO (رمز الشارت فقط)             │
├─────────────┬─────────────┬──────────────┬───────────────────┤
│ Phase Engine│ Long Wave   │ Volume Engine│ Elliott (heuristic)│
│ 8 مراحل     │ E/B/M scores│ 6 تصنيفات    │ أساسي + بديل + inv │
├─────────────┴─────────────┴──────────────┴───────────────────┤
│ Time cycles (Gann ± + bars since pivot) │ MTF D/W/M/60       │
├──────────────────────────────────────────────────────────────┤
│ Buy zones + Stop + T1/T2/T3 + R/R + تحذير مطاردة             │
├──────────────────────────────────────────────────────────────┤
│ Opportunity Rank 0–100 (أوزان قابلة للتعديل)                 │
└──────────────────────────────────────────────────────────────┘
```

**مبدأ انتقائي:** لا تُعتبر الإشارة «شراء» إلا عندما ترتفع **المرحلة** (2–5)، و**درجة الموجة**، و**R/R** معًا. المرحلة 7–8 أو `Chase Warn` تخفض الترتيب أو تُظهر تجنبًا.

## 2. محركات التحليل

### 2.1 محرك المراحل (Phase Engine)

| # | المرحلة | معنى مختصر |
|---|---------|------------|
| 1 | اتجاه هابط | بنية/اتجاه يومي سلبي |
| 2 | قاعدة محتملة | تماسك + انكماش ATR + مدة قاعدة |
| 3 | تجميع محتمل | قاعدة + `Potential Accumulation` |
| 4 | استعداد اختراق | قرب مقاومة + ضغط |
| 5 | اختراق مؤكد | BOS + RVOL ≥ 1.25 |
| 6 | اتجاه صاعد | بنية صاعدة + يومي + فوق EMA200 |
| 7 | ممتد / مخاطر | RSI مرتفع أو قرب مقاومة بعد صعود |
| 8 | فشل السيناريو | فشل اختراق / كسر دعم / تصريف حجم |

**الشروط الناقصة** تظهر في اللوحة (ضعف هبوط، قيعان أعلى، انكماش، حجم، أسبوعي، R/R، …).

### 2.2 Long Wave Detector

ثلاث درجات مستقلة 0–100 (ليست «موجة مؤكدة»):

- **Early Setup:** قاعدة، ضعف هبوط، تجميع حجمي، أسبوعي.
- **Breakout Setup:** قرب مقاومة، ضغط، قيعان أعلى، MTF.
- **Momentum Setup:** BOS، حجم اختراق، اتجاه — مع خصم RSI مرتفع وتباعد حجم.

`longWaveScore = max(E, B, M)` ونوع الفرصة يُعرض في اللوحة.

### 2.3 محرك الحجم

| التصنيف | متى |
|---------|-----|
| Volume Expansion | RVOL عالي + شمعة ضيقة أو إغلاق ضعيف |
| Potential Accumulation | نقاط تجميع > تصريف |
| Potential Distribution | العكس |
| Breakout Confirmation | BOS + RVOL |
| Climax Risk | RSI مرتفع + سعر↑ حجم↓ |
| Unconfirmed Activity | نشاط حجمي غير معتاد بدون دليل كافٍ |

**تنويه:** من OHLCV لا يُستنتج Delta أو Footprint أو هوية «مؤسسات».

### 2.4 Elliott Wave

عد استكشافي من pivots كبيرة (`i_wavePivot`): دافعة محتملة، ABC، أو «غير محسوم» مع **إلغاء** (كسر pivot/دعم). لا يُعرض كحقيقة — فقط سينario + بديل.

### 2.5 التحليل الزمني

- شموع منذ آخر pivot.
- نوافذ Gann اختيارية (9/18/27/45/90) ± `i_timeTol`.
- **عدم يقين** صريح عند غياب تزامن.

### 2.6 MTF

`request.security` مع `lookahead_off` — لا تُستخدم شمعة أسبوع/شهر غير مكتملة كتأكيد نهائي على intraday.

### 2.7 Opportunity Ranking (/100)

مكونات (أوزان في المدخلات): بنية/مرحلة، قاعدة، حجم، اختراق، MTF، موجي، منطقة، R/R.  
**لا تُكرر** نفس الإشارة: مثلاً BOS يدخل في المرحلة والاختراق وليس مرة ثالثة في «زخم» منفصل بنفس الوزن.

## 3. إعدادات مقترحة لأسهم EGX

| المعامل | قيمة ابتدائية | ملاحظة |
|---------|---------------|--------|
| الإطار | **يومي** للاكتشاف؛ 60د للمضاربة بعد تأكيد يومي | |
| `i_minAvgVol` | 1000–5000 حسب السهم | رفع للأسهم الرئيسية، خفض بحذر للصغيرة |
| `i_rvolClimax` | 2.0 | RVOL > 2 = نشاط استثنائي |
| `i_pivotLen` | 5 | زيادة = أقل إشارات، أكثر تأخير pivot |
| `i_baseMinBars` | 15 | قاعدة أطول للأسهم البطيئة |
| `i_minRR` | 1.5 | 2.0+ للانتقائية |
| `i_rankMin` | 58–65 | فرص «قوية» |
| `i_nearResPct` | 1.5% | قرب مقاومة |
| Strategy | عمولة **0.125%**، انزلاق **2** tick | تقريب EGX |

**رموز للاختبار اليدوي (TradingView):** `EGX:COMI`, `EGX:SWDY`, `EGX:TMGH`, `EGX:EAST`, `EGX:FWRY` — توفر البيانات يختلف حسب الاشتراك.

## 4. إشارات الدخول والخروج (منطق المؤشر)

| نوع | شرط تأكيد (مختصر) | وقف | إبطال |
|-----|-------------------|-----|--------|
| داخل قاعدة | CHoCH / قيعان أعلى + حجم تجميع | تحت منطقة طلب | كسر `activeStop` |
| بعد اختراق | إغلاق فوق مقاومة + RVOL | تحت pivot الاختراق | فشل retest / `fakeBreakUp` |
| إعادة اختبار | low عند دعم + إغلاق فوقه | تحت الدعم | مرحلة 8 |
| استثماري | أسبوعي+ شهري+ فوق EMA200 + تجميع | `investInv` / دعم طويل | تصريف حجم |

**خروج / تجنب:** مرحلة 8، `Potential Distribution`, `Chase Warn`, R/R < `i_chaseRR`.

## 5. الاختبار التاريخي (Strategy)

1. افتح `EGX_WAVE_HUNTER_PRO_STRATEGY.pine` في Pine Editor → Add to chart.
2. اختر **إطار يومي** ورمز EGX سائل.
3. Strategy Tester → راجع: عدد الصفقات، Win %، Profit Factor، Max DD، Net profit **بعد** العمولة.

**لم يُشغَّل المحاكي من هنا** — النتائج تظهر فقط على حسابك بعد التشغيل. لا تُذكر نسب نجاح وهمية.

**تحيزات يجب مراعاتها:**

- البقاء على أسهم نشطة فقط (selection bias).
- حدود السعر اليومية EGX غير مُنمذجة في Pine.
- فجوات الافتتاح قد تتجاوز الوقف نظريًا.
- فصل: اضبط المعاملات على فترة → اختبر على فترة لاحقة يدويًا (walk-forward).

## 7. قيود Pine وEGX (لا يتجاوزها المؤشر)

| غير متاح | البديل في المؤشر |
|----------|-------------------|
| مسح كل أسهم EGX تلقائيًا | مؤشر **للرمز المعروض** + قائمة مراقبة يدوية |

| «صفقات مؤسسات» مؤكدة | «تجميع/تصريف **محتمل**» |

| Gann / دورات كقانون | نوافذ + تكرار تاريخي محدود |
| اختبار out-of-sample تلقائي | Strategy Tester يدوي + فترات منفصلة |
