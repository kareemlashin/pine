## Pine Script v6 — ما يُنفَّذ داخل Pine وما يحتاج مصدرًا خارجيًا

### ممكن مباشرة (OHLCV + رموز المؤشرات على TradingView)

| المحرك | التنفيذ في `EGX_CYCLE_MASTER.pine` |
|--------|-------------------------------------|
| 1 — Market Regime | EGX30 / EGX70 EWI / EGX100 EWI: اتجاه، ADX، RVOL، زخم 20 جلسة؛ تصنيف 8 حالات؛ **بدون** اتساع سوق حقيقي |
| 2 — Relative Strength | نسبة السهم ÷ المؤشر (افتراضي EGX30) + زخم RS؛ رمز قطاع اختياري |
| 3 — Stock DNA | إحصاء موجات مكتملة بين pivots مؤكدة (مدة، % صعود، % تصحيح) |
| 4 — Pattern similarity | تشابه متجه سمات (قبل الحدث فقط) → عائد لاحق 5/10/20/40/60 |
| 5 — Time cycles | فترات بين pivots، Gann اختياري، تأخير/تقدم vs المتوسط |
| 6–8 — Volume / pre-rally / سلوك متوافق | RVOL، CMF، OBV، acc/dist، امتصاص/تصريف/اختراق ضعيف السيولة |
| 9 — اتجاه مدمج | MTF + بنية + حجم + دورة |
| 10 — أهداف | Fib / قياس / مقاومة / موجي → T1–T3 + إبطال |
| 11 — Opportunity Score | مكونات منفصلة 0–100 بدون تكرار واضح |

### غير متاح أو غير موثوق في Pine (لا يُدّعى)

- **Breadth EGX**: نسبة الأسهم الصاعدة، % فوق MA، قمم/قيعان جديدة لكل السوق — تحتاج مسح آلاف الرموز أو API.
- **بديل معروض**: مقارنة أداء EGX30 vs EGX70 vs EGX100 (صعود ضيق vs واسع).
- Footprint، Delta، عدد صفقات حقيقي، هوية مؤسسات/ميكر.
- «تنبؤ AI» — النظام **إحصاء تشابه تاريخي** وليس تعلمًا آليًا.
- مسح عدة أسهم في وقت واحد: **مؤشر واحد = رمز الشارت**؛ للمسح استخدم Watchlist يدويًا أو Python خارج TV.

### قيود Pine ذات صلة

- `request.security`: محدود (~40 استدعاءً) — المؤشر يجمع بيانات المؤشرات في packs.
- Pivot مؤكد يتأخر `pivotLen` شموع — ليس repainting لكن تأخير طبيعي.
- حلقات التاريخ capped (`lookback` مدخل) للأداء.
- عينة صغيرة → تحذير صريح في اللوحة.

1. Pine Editor → الصق `pine/EGX_CYCLE_MASTER.pine` → Save → Add to chart.

## قراءة Opportunity Score

- **62+** مع R/R كافٍ وDistRisk منخفض: فرصة نسبية — **ليس ضمانًا**.
- **52–62**: مراقبة / تأكيد.
- تصريف محتمل أو DistRisk ≥ 70: حذر.
- **Pattern n &lt; 8**: استنتاج تشابه ضعيف.
